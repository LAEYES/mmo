# FreedomArena Asset Export

Dossier cible pour les exports Canva destinés à Unity.

## Organisation

- Tiles/
  - Floors
  - Borders
  - Transitions
  - Walls
  - Platforms
  - Stairs
  - Bridges
- Biomes/
  - NaturalTerrain
  - Water
  - Energy
  - Plasma
- Tech/
  - Doors
  - Consoles
  - Panels
  - Industrial
- Gameplay/
  - Obstacles
  - Spawn
  - Combat
  - Sanctuaries
  - Teleporters
  - Objectives
- Icons/
  - Items
  - Resources
  - Factions
  - Classes

Les fichiers exportés depuis Canva doivent être importés comme sprites Unity selon le manifeste :
Assets/Resources/FreedomArena/FreedomArenaTileCategories.json
